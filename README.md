
# COS 201 - Computer Programming I
## Week 3 Java Programs

This repository contains three Java programs developed for COS 201.

### Programs

1. SimpleCalculator.java
   - Performs addition, subtraction, multiplication and division.

2. AverageCalculator.java
   - Calculates the average of three numbers.

3. ItemCost.java
   - Calculates the total cost of items using price and quantity.

### Requirements
- Java Development Kit (JDK)

### How to Compile and Run

Compile each program using:

javac SimpleCalculator.java
java SimpleCalculator

javac AverageCalculator.java
java AverageCalculator

javac ItemCost.java
java ItemCost
